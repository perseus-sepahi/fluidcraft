FluidCraft Guide

FluidCraft is a computational fluid dynamics (CFD) app for macOS. You set up the case, mesh it and look at the results in FluidCraft; OpenFOAM solves it. Meshes come from OpenFOAM's blockMesh and snappyHexMesh and from Gmsh.

Getting started

What you need

ProgramNeeded for
OpenFOAM (ESI release, v2406 or newer)Required: every calculation, block meshes, prism layers, mesh conversion.
GmshRequired for the Gmsh templates, CAD import and CAD analysis.
ParaViewOptional: opening an OpenFOAM case in ParaView.
Python 3 with NumPyOptional: Python post-processing scripts. PyTorch for neural networks is installed from Settings › Machine Learning.

Open FluidCraft › Settings › Tools. It shows which of these are installed, with their versions, and installs a missing one with Homebrew when you click Install…. The status in the top-right corner of the window (a green or orange dot next to “OpenFOAM”) opens the same page.

FluidCraft needs macOS 15 or later. The OpenFOAM app for macOS runs on Apple silicon (M1 or later).

Your first case in two minutes

  1. On the Start page, click Lid-driven cavity under Learn with a Tutorial.
  2. Press ⌘R (Solve › Calculate). OpenFOAM runs; the residuals appear under Scaled Residuals.
  3. When it finishes, choose Contours in the sidebar (or the Contours button in the toolbar) to see the velocity field.

A case, step by step

  1. Mesh. Generate one (Mesh Generation), import one (File › Import Mesh…), or let a module or tutorial build it. Mesh & Quality reports cell counts and quality.
  2. Setup. General (steady or transient, gravity), Models (turbulence, energy, scalars), Materials, Cell Zone Conditions (fluid, solid, porous, rotating zones), Boundary Conditions (inlets, outlets, walls, symmetry, periodic), Named Expressions (formulas of x, y, z and t), Reference Values (for force coefficients).
  3. Solution. Methods and Controls (schemes and relaxation), Report Definitions and Monitors (forces, flows, averages), Initialization, OpenFOAM (application, turbulence model, cores and every advanced setting), then Run Calculation.
  4. Results. Surfaces, mesh display, contours, vectors, pathlines, XY plots and reports.

Everything a module or tutorial sets up stays editable on these pages.

Meshing

  • Block meshes (channels, boxes, obstacles, graded spacing) and a cylinder O-grid are made by OpenFOAM's blockMesh.
  • Gmsh templates: a cylinder in a channel, a NACA airfoil, a pipe, and CAD models (external or internal flow).
  • snappyHexMesh meshes CAD models with refinement and prism layers (Mesh Generation › snappyHexMesh, or the CAD Analysis mesher choice).
  • Prism layers on 3D Gmsh meshes come from snappyHexMesh's layer addition; set the first-layer height or let the y⁺ calculator size it.
  • Importing: ASCII Fluent .msh/.cas files are converted by OpenFOAM's fluentMeshToFoam, 3D Gmsh files by gmshToFoam, and OpenFOAM case folders are read directly. The console says which converter read the file. Binary files and 2D Gmsh meshes are read by FluidCraft itself. Fluent HDF5 files (.cas.h5) are not supported: export an ASCII mesh from Fluent.
  • Native CAD formats (SolidWorks, CATIA, Parasolid…) need a converter command, set in Settings › General. Otherwise export STEP from your CAD program.

Running OpenFOAM

Run Calculation (or ⌘R) writes the case into ~/FluidCraft/<case title> and runs it. FluidCraft picks the OpenFOAM application from your setup (simpleFoam, pimpleFoam, buoyant and compressible solvers, chtMultiRegionFoam for conjugate heat transfer, rhoCentralFoam for supersonic flow); the OpenFOAM page lets you override it and set the number of cores.

The case folder is a normal OpenFOAM case with an Allrun script, so you can also run it in a terminal or on another computer. Solve › Load OpenFOAM Results reads results back.

Custom OpenFOAM content. A case can carry extra stages, function objects or dictionary text. OpenFOAM features such as #codeStream can run programs, so when you open a case from someone else that contains such content, FluidCraft lists it and asks you to approve it before anything runs.

Results

  • Contours, Vectors, Pathlines on the boundaries or on your own planes and iso-surfaces (Results › Surfaces).
  • XY Plot: a field along a line.
  • Reports: forces and coefficients, mass flow, surface and volume averages; also plotted during the run (Report Plots).
  • ParaView: Solve › Open OpenFOAM Case in ParaView, or File › Export › Solution to ParaView.
  • Pictures: the camera button above the graphics saves a PNG with the legend.

Python scripts

Post-Processing › Python scripts runs your own scripts on the solution with the fluidcraft_post module:

import numpy as np
import fluidcraft_post as cp

case = cp.load()
speed = np.linalg.norm(case["U"], axis=1)
cp.report("max speed", speed.max(), "m/s")

Reports appear in FluidCraft; figures and new fields are saved with the case. Scripts use the Python set in Settings › Machine Learning and never run through a shell. Scripts in a case you open from someone else ask for approval first. Older scripts that import curlew_post still work.

AI assistant and PINNs

The AI Assistant answers questions about your case. Choose the provider in Settings › AI: Anthropic Claude, an OpenAI-compatible service, or a local model through Ollama (which never leaves your Mac). API keys are kept in the macOS Keychain.

Privacy. Nothing is sent anywhere until you ask a question. Your question, and a summary of the open case when Send case summary is on, then go to the provider you chose, under that provider's terms. FluidCraft has no server of its own and collects nothing.

The Physics-Informed Neural Network module trains a network on the case's equations (and, in hybrid mode, on samples of the OpenFOAM solution). It needs PyTorch: Settings › Machine Learning › Install PyTorch… sets it up.

Console and command line

The console under the graphics accepts commands; type help for the list. For example:

/tutorial cavity
/solve/iterate 500
/display/contour pressure
/report/forces

The app bundle contains a command-line tool for batch runs and validation:

/Applications/FluidCraft.app/Contents/Helpers/fluidcraft tutorial cavity
/Applications/FluidCraft.app/Contents/Helpers/fluidcraft validate all --cores 4

Troubleshooting

“OpenFOAM is not installed”

Install it from Settings › Tools, or by hand with brew install gerlero/openfoam/openfoam. If you installed it somewhere unusual, choose it on the OpenFOAM page › Installation.

A run stops with an error

The console shows the last lines of the failing OpenFOAM step. The full logs (log.simpleFoam and so on) are in the case folder: OpenFOAM page › Reveal in Finder. Common causes: a poor mesh (check Mesh & Quality), a time step that is too large in a transient run, or boundary conditions that do not fit together (for example no outlet).

The mesh check shows problems

Cells with non-positive volume must be fixed before running. Low orthogonal quality slows convergence: refine the mesh, or raise nNonOrthogonalCorrectors on the OpenFOAM page.

macOS says the app cannot be opened

Builds from the FluidCraft website are signed and notarized. A build you made yourself is only signed for your Mac: right-click it and choose Open the first time.

Reporting a problem

Help › Report an Issue opens the issue tracker. Please include the console output and, if you can, the case.
